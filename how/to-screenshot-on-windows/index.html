How to screenshot on Windows

Quick answer: Press Win + Shift + S, drag a region, then paste or find it in your Screenshots folder.

All methods

  • Win + Shift + S — Snipping Tool overlay; copy to clipboard
  • PrtScn — full screen to clipboard
  • Win + PrtScn — full screen saved to Pictures\Screenshots
  • Alt + PrtScn — active window to clipboard
  • Win + G — Game Bar (for games; use the capture widget)
  • Snipping Tool app — for delayed or shaped captures

Where do they go?

Win + PrtScn saves to This PC → Pictures → Screenshots. Other methods copy to the clipboard — paste into Paint, Word, or a chat window.
